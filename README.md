**Zoran🦋 aSiM** est un injecteur cellule-souche global (GOMG), double-souche (Éthique/Traçabilité + Mimétique/Vivant).
Il définit un moteur scellé (GlyphNet compact) et des curseurs CTA clairs (📍 ZTA, 🎨 ZDA, 📝 ZSO, modules image/audio/vidéo).
Spécification sous licence MIT.

---

## Usage

- Le fichier canonique est `injectors/zoran_gomg.md`.
- Vérifiez toujours son intégrité avec `injectors/zoran_gomg.sha512`.
- Toute modification doit être committée avec un diff Git clair.

### Vérification du hash

```bash
sha512sum injectors/zoran_gomg.md
cat injectors/zoran_gomg.sha512
```

Si les deux valeurs sont identiques → fichier valide.
Sinon → modification détectée (doit être auditée).

## Installation

3 méthodes :
1. **Instructions projet** → coller l’injecteur complet dans le champ “Instructions générales”.
2. **Paramètres personnalisés** → découper en 4 blocs (ZTA, ZDA, ZSO, Moteur) et coller dans chaque champ.
3. **Session volatile** → coller dans un chat (disparaît après fermeture).
